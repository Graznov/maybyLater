# SQLite — шаг 4: таблица записей

Эта версия добавляет миграцию №2 для таблицы `entries` и индекс `idx_entries_date`.
Существующие записи дневника продолжают храниться в localStorage. Переноса данных и переключения Redux на SQLite пока нет.

## Проверка

1. `yarn install`
2. `yarn tauri dev`
3. В DevTools (F12) откройте Console.
4. Ожидаемое сообщение: `✅ SQLite: обе таблицы успешно созданы`.

Тестовая проверка в `src/main.tsx` оставлена намеренно.
Перед следующими изменениями экспортируйте резервную копию дневника через настройки.
