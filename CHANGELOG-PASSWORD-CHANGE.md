# MaybeLater — исправления смены пароля (архив для проверки)

Изменены `src-tauri/src/lib.rs`, `src-tauri/src/password_change.rs` (новый), `src/pages/SettingsPage.tsx`.

- При смене пароля закрывается активная SQLite-сессия, а фронтенд блокирует новые записи и ждёт автосохранение.
- Проверенная копия базы создаётся с новым паролем; исходная база сохраняется под уникальным именем `maybe-later-before-password-change-*.db`.
- Перед переименованием создаётся маркер `maybe-later-password-change-pending`. Если приложение прервалось между двумя переименованиями, при следующем запуске база восстанавливается из резервной копии.
- Если новая база уже установлена, восстановление не перезаписывает её. Маркер очищается после успешного разблокирования.
- При неудачной проверке новой базы предусмотрен откат. Добавлены 3 изолированных Rust-теста сценариев восстановления.
- В настройках появилась секция «Безопасность» с вводом старого, нового и подтверждением нового пароля.

cargo test --lib --locked
cargo check --locked
cd ..
yarn build
